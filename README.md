# NBA Analytics Dashboard 🏀

## Descripción

Proyecto de visualización y análisis de datos de la NBA, desarrollado como parte de mi formación en Ciencia de Datos.

## Objetivo

Explorar y presentar información del baloncesto profesional mediante una visualización interactiva que facilite la interpretación de los datos.

## Tecnologías

- HTML
- Visualización de datos
- Análisis exploratorio de datos

## Contenido

- `NBA_Analytics_Dashboard.html`: archivo HTML con el dashboard y sus visualizaciones.

## Cómo visualizarlo

Descarga el archivo HTML y ábrelo en un navegador web. Si los gráficos dependen de librerías o archivos externos, será necesaria una conexión a internet o incluir los recursos correspondientes.
